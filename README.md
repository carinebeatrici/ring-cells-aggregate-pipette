# ring-cells-aggregate-pipette
Simulation of a cell aggregate being pulled by a micropipette 


# Requirements

julia

# Run

Edit file main_pars.txt to select simulation parameters for each experiment of the batch.
Experiments will be executed one by one sequentially.

To execute the program just run the following command in terminal:
julia rings-v8.7.jl

Or in Julia REPL:
include("rings-v8.7.jl")
